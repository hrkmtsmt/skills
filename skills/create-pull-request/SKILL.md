# プルリクエストの基本ルール

- 人間が読む前提で完結に書くこと

## フォーマット

- 基本的にはリポジトリの@.github/PULL_REQUEST_TEMPLATE.mdに従うこと
- テンプレートが存在しない場合は[@PULL_REQUEST_TEMPLATE.md](./PULL_REQUEST_TEMPLATE.md)に従うこと

## 記載すべき内容

- 必ずWHYや変更した背景を記載すること
- WHYや変更理由は推測せず、人間に尋ねること

## ベースブランチ

- プルリクエストのベースブランチは基本的にはデフォルトブランチにすること
- プルリクエストが数珠つなぎになっている場合はベースブランチは手前の作業ブランチにすること
